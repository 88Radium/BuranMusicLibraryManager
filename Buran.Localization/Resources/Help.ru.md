# Buran — Руководство

Buran ведёт музыкальную библиотеку: правит ID3-теги файлов MP3 и FLAC и хранит собственный каталог исполнителей, жанров и настроений. Изменения тегов сразу записываются в файл.

## Настройки

Кнопка «Настройки» справа вверху открывает меню.

- Язык: немецкий, английский, русский или язык системы. Интерфейс и это руководство следуют выбору.
- Размер шрифта: мелкий, средний или крупный.
- Прозрачность: непрозрачность главного окна.

## Библиотека

Левая колонка — дерево папок.

- Добавить папку: добавить корневую папку в библиотеку. Можно несколько корней; список сохраняется.
- Удалить: убрать библиотеку выбранной папки из списка.
- Обновить: перечитать дерево.
- Подпапка с синей точкой содержит аудиофайлы. Щелчок загружает их в ID3-редактор.
- Поддерживаемые файлы: MP3 и FLAC.

## ID3-редактор

Первая вкладка рабочей области. Компактная таблица (название, исполнители, путь папки, альбом, год, длительность, битрейт, частота, разрядность). Столбцы можно включать через «Столбцы». Правый щелчок по треку: «Открыть папку» выбирает папку в библиотеке слева и показывает её файлы.

«Править теги» открывает инспектор справа; разделитель меняет только ширину инспектора. Групповые действия — только в этом режиме, для отмеченных файлов.

«Сбросить» после «Показать треки» снова загружает выбранную папку библиотеки или первый корень, если ничего не выбрано.

Если плеер загружен, транспорт и спектрограмма стоят под списком (разделитель меняет высоту). Без плеера редактор работает сам.

### Выбор и групповые действия

- Все / Нет: отметить или снять все файлы.
- Исполнители / Жанры / Настроения: групповой диалог для выбора (см. ниже).
- Комментарии: задать один комментарий или очистить комментарии выделенных файлов.
- Играть / В плейлист: передать выбор модулю плеера (если плеер загружен).
- Имя файла из ID3: переименовать выбранные файлы по тегам.
- ID3 из имени файла: прочитать теги из имени файла и записать их.

### Поля файла

- Флажок выбора, название, альбом, имя файла, год выпуска, комментарий.
- Битрейт только для просмотра.
- Исполнители, жанры и настроения — списки: X удаляет запись, + или Enter добавляет. Подсказки берутся из каталога (предпочитаемые имена и альтернативы).
- Неизвестные имена добавляются как предпочитаемая запись каталога, если они не заблокированы. Заблокированные значения попадают в файл, но не в базу.
- Из ID3 в имя файла / Из имени файла в ID3: только этот файл.
- Сбросить ID3: вернуть теги файла к состоянию на момент загрузки.

При открытии папки альтернативные написания в файлах заменяются на предпочитаемое имя каталога и сохраняются.

### Групповой диалог исполнителей, жанров и настроений

Список — объединение всех выбранных файлов.

- Удалить запись: она снимается только там, где уже есть.
- Добавить или «все»: записывает значение на каждый выбранный файл, даже если оно уже в списке.
- Загрузить из выбора: собрать список заново из файлов.
- Применить записывает теги. Неизвестные имена попадают в каталог, заблокированные — нет.

### Групповые комментарии

Одно текстовое поле и предпросмотр по файлам. Применить заменяет комментарий в каждом выбранном файле. Пустое поле очищает его.

### Имя файла из ID3 и конфликты

Если целевое имя уже существует, открывается «Сравнить файлы» (размер, изменение, длительность, битрейт, частота, каналы, разрядность, формат).

- Оставить оба: отменить переименование, оба файла остаются.
- Оставить этот файл: удалить существующий и переименовать этот.
- Оставить существующий: удалить этот файл и оставить уже лежащий.

### ID3 из имени файла

Имя файла разбирается по шаблонам и ключевым словам (исполнители, название, альбом, год, пометки версии вроде Live или Remix). Запятая и точка с запятой разделяют всегда. Остальные разделители задаются в «Ключевых словах» редактора БД.

«feat.» / «ft.» / «featuring» в имени файла — в том числе в скобках, например `Eminem - Stan (feat. Dido).mp3` — читаются как дополнительные исполнители, а не как комментарий. `(Live)` или `[Remix]` остаются комментарием.

Известные имена каталога и однобуквенные фрагменты (например «D & F») не разрезаются.

## Новые значения для базы данных

После загрузки папки этот диалог появляется, если в тегах или именах файлов есть имена, которых ещё нет в каталоге и которые не заблокированы.

Для каждой записи:

- Флажок: импортировать или пропустить.
- Предпочитаемое имя: новая запись каталога.
- Альтернативное имя: написание существующей предпочитаемой записи. Для исполнителя предпочитаемое имя можно создать сразу здесь.
- Блокировать: больше не предлагать. Блокировка жанра «Happy» не блокирует настроение «Happy».

Внизу: заблокированные значения с «Разблокировать». Разблокировка возвращает имя в список сверху, чтобы его можно было сразу импортировать.

Применить записывает только отмеченные пункты. Пропустить закрывает без изменений.

## Плеер

Отдельный модуль. MP3 и FLAC через libVLC. Вместе с ID3-редактором транспорт и спектрограмма крепятся под списком; вкладка плеера оставляет очередь папки и плейлисты. Без редактора вкладка плеера полная.

- Play / Пауза / Стоп / Назад / Далее, позиция, громкость.
- Спектрограмма (как Spek, один раз). Оси: Гц, время, дБ до частоты Найквиста файла. Клик или перетаскивание — перемотка. Разделитель меняет высоту. Так видно, есть ли у файла 192 кГц энергия выше 16 кГц.
- Слева: файлы выбранной папки. Двойной щелчок — воспроизведение, «В плейлист» — добавление.
- Справа: именованные плейлисты, которые могут включать файлы из разных папок. Создание, переименование, удаление.
- Импорт и экспорт M3U (абсолютные пути). Отсутствующие файлы остаются в списке с пометкой.
- Из ID3-редактора: «Играть» и «В плейлист» для выделения.

Воспроизведение плейлиста продолжается при смене папки. Очередь папки останавливается, если текущего трека нет в новой папке.

## Редактор БД

Вторая вкладка. Полный каталог: создание, переименование, привязка как альтернативы, блокировка и разблокировка.

### Поиск и обновление

Поиск фильтрует исполнителей, альтернативные имена и ключевые слова. «Очистить поиск» сбрасывает его. «Обновить» перечитывает каталог.

### Исполнители

Список с предпочитаемым и настоящим именем. Правый щелчок: Удалить, Блокировать, Снять выделение, Показать треки (индексированные треки исполнителя в ID3-редакторе, включая путь папки).

Добавление внизу:

- Предпочитаемое имя: новый исполнитель, при желании с настоящим именем.
- Альтернативное имя: привязать введённое имя к существующему предпочитаемому исполнителю. Ввод в поле (например «E») фильтрует список.
- Блокировать: скрыть введённое имя навсегда. Если оно уже в каталоге, запись удаляется. Блокировка предпочитаемого имени блокирует и его альтернативы.

### Альтернативные имена

Колонка всех альтернатив или только выбранного исполнителя. Для добавления нужен выбранный исполнитель. Удаление и блокировка — через правый щелчок или кнопки.

### Участие в группах

Только при выбранном исполнителе. Участники этой группы либо группы, в которые входит исполнитель. Имена уже должны существовать как исполнители. Группа не может быть участником самой себя.

### Жанры и настроения

Одинаковое управление для обоих.

- Флажок: назначить жанр или настроение выбранному исполнителю.
- Правый щелчок: Удалить, Блокировать, Снять выделение, Фильтровать по выделению (список исполнителей), сбросить фильтр, Показать треки.
- Альтернативные написания: варианты выбранной записи. + добавляет, Блокировать скрывает введённый вариант.
- Добавление внизу: предпочитаемое имя или альтернатива существующей записи, плюс Блокировать.

### Ключевые слова

Разделители и слова распознавания для имён файлов и тегов.

- Сотрудничество: делит исполнителей (feat, ft, vs, with, and и знаки вроде & + /).
- Версия: распознаёт пометки вроде Live, Remix, Remaster.

Запятая и точка с запятой всегда остаются разделителями. Слова и знаки в этом списке можно добавлять и удалять; уберите &, если он не должен делить имена.

### Заблокированные значения

Нижняя полоса, отдельно для исполнителей, жанров и настроений. Разблокировать снова разрешает имя как подсказку. Сама запись каталога при этом не восстанавливается.

Позднее добавление того же написания в каталог снимает блокировку только для этого написания.

## Модель каталога

Три вида, каждый отдельно: исполнитель, жанр, настроение.

- Предпочитаемое имя: написание, которое должно попадать в файлы.
- Альтернатива: другое написание той же записи. При открытии папки заменяется на предпочитаемое имя.
- Заблокировано: больше не предлагается в диалоге импорта и не записывается в каталог молча.

Блокировка действует только на выбранный вид. Одна и та же строка может быть заблокирована как жанр и разрешена как настроение.

Редактор БД умеет всё, что умеет диалог импорта: создать предпочитаемое имя, привязать альтернативу, блокировать и разблокировать.
