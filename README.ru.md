Buran для тех, кто хочет привести большую коллекцию MP3/FLAC в порядок: единые имена исполнителей, аккуратные имена файлов, жанры и настроения — и слушать по пути. **Свой каталог — источник истины**, не MusicBrainz и не iTunes. Предпочтительное написание, альтернативы и список блокировок применяются сами при следующем открытии папки.

Изменения тегов **сразу записываются в файл**. Отдельной кнопки «Сохранить» нет.

| | |
|---|---|
| Файлы | MP3 и FLAC |
| Платформы | Linux (RPM, в том числе Fedora / Bazzite) и Windows |
| Плеер | libVLC входит в пакет |
| Языки | немецкий, английский, русский или язык системы |
| Данные | каталог и настройки лежат в папке пользователя, не в музыкальной библиотеке |

То же руководство есть в приложении: **Настройки → Руководство**.

## Установка

Готовые установщики — на странице **[Releases](https://github.com/88Radium/BuranMusicLibraryManager/releases)**.

### Linux (Fedora, RHEL, Bazzite)

1. Скачайте `.rpm` нужного релиза (например `buran-0.1.3-4.x86_64.rpm`).
2. На **Bazzite / rpm-ostree**:

```bash
sudo rpm-ostree uninstall buran --install /путь/к/buran-*.x86_64.rpm
sudo systemctl reboot
```

Первая установка без предыдущего пакета:

```bash
sudo rpm-ostree install /путь/к/buran-*.x86_64.rpm
sudo systemctl reboot
```

3. Запускайте ярлыком **Buran Music Library Manager** или командой `buran`.

Не вызывайте `/usr/lib/buran/BuranUI` напрямую. Обёртка задаёт `LD_LIBRARY_PATH` и `VLC_PLUGIN_PATH`, чтобы плеер нашёл встроенные библиотеки VLC.

Debian/Ubuntu: к релизу также приложен `.deb`. Это сопутствующий пакет; Linux-библиотеки внутри собраны под Fedora.

### Windows

1. Скачайте и запустите `Buran-<версия>-win-x64-setup.exe`.
2. Приложение ставится в `%LOCALAPPDATA%\Programs\Buran` и в меню «Пуск».
3. Либо распакуйте портативный `.zip` и запустите `BuranUI.exe`.

При первом запуске Windows может показать SmartScreen (файл не подписан). Тогда **Подробнее → Выполнить в любом случае**.

libVLC и `ffmpeg.exe` (для спектрограммы) входят в пакет Windows. Отдельно ставить VLC или ffmpeg не нужно.

## Первый запуск

1. Откройте Buran.
2. Слева **Добавить папку** и выберите корень музыкальной библиотеки (например `Музыка`).
3. В дереве щёлкните подпапку с синей точкой — там лежат MP3/FLAC.
4. Файлы появятся на вкладке **ID3-редактор**.
5. Сверху **Править теги**, чтобы открыть инспектор и групповые действия.

Можно несколько корней (внутренний диск и шара NAS). Список запоминается.

## Функции

### Настройки

Справа вверху, кнопка **Настройки**.

| Параметр | Что делает | Зачем | Как пользоваться |
|---|---|---|---|
| **Язык** | Переключает интерфейс и встроенное руководство. | Немецкий, английский, русский или язык системы. | Откройте список, выберите язык. Действует сразу. |
| **Размер шрифта** | Мелкий / средний / крупный. | Длинные списки тегов и мониторы 4K. | Откройте список, выберите размер. |
| **Прозрачность** | Непрозрачность окна (от 40 %). | Просвечивать рабочий стол. | Ползунок. |
| **Руководство** | Открывает справку в приложении. | Тот же обзор функций, без GitHub. | Кнопка **Руководство**. |

### Библиотека

Левая колонка — дерево папок коллекции.

#### Добавить папку

**Что:** Делает папку корнем библиотеки.  
**Зачем:** Структура как в проводнике, без выбора каждый раз.  
**Как:**

1. **Добавить папку**.
2. Выберите верхнюю музыкальную папку.
3. Раскрывайте дерево.

#### Удалить

**Что:** Убирает выбранный корень из списка. Файлы на диске остаются.  
**Зачем:** Старая флешка или переименованный путь больше не должны мелькать.  
**Как:** Выделите корень → **Удалить** или правый щелчок в дереве.

#### Обновить

**Что:** Перечитывает дерево.  
**Зачем:** После создания или переименования папок вне Buran.  
**Как:** **Обновить**.

#### Включать подпапки

**Что:** При открытии папки подгружаются и файлы из подпапок.  
**Зачем:** Альбом с `CD1` / `CD2` или «весь Metal сразу».  
**Как:** Поставьте галочку, затем щёлкните папку в дереве.

#### Индексировать библиотеку

**Что:** Пишет название, исполнителя, альбом, путь и т. д. в локальный индекс каталога.  
**Зачем:** В редакторе БД **Показать треки** — все проиндексированные пьесы исполнителя, жанра или настроения, включая путь папки.  
**Как:**

1. Добавьте хотя бы один корень.
2. **Индексировать библиотеку**.
3. Позже в редакторе БД: правый щелчок → **Показать треки**.

#### Синяя точка

Подпапка с точкой содержит аудиофайлы. Щелчок загружает их в ID3-редактор.

### ID3-редактор

Основная рабочая область. Здесь живут теги и имена файлов.

#### Таблица

**Что:** Компактный список всех файлов выбранной папки: название, исполнители, путь, альбом, год, длительность, битрейт, частота, разрядность.  
**Зачем:** Обзор, сортировка, поиск нужного файла без открытия каждого.  
**Как:**

1. Слева выберите папку с аудио.
2. Щёлкните строку — это **сфокусированный трек** (инспектор, сброс, воспроизведение двойным щелчком).
3. **Галочка** в первом столбце — **множественный выбор** для групповых действий. Фокус и галочки независимы: можно смотреть трек A, отметив B и C.

**Столбцы**

- **Столбцы** сверху: галочки показывают или скрывают столбцы.
- Перетаскивание заголовков меняет порядок, край — ширину.
- **Имя файла**, **Жанр** и **Настроение** по умолчанию скрыты, чтобы таблица не расползалась.

**Правый щелчок → Открыть папку**

Выбирает слева папку этого файла и показывает все треки в ней. Удобно после **Показать треки** из редактора БД, когда попадания разбросаны по папкам.

**Сбросить фильтр**

Если список отфильтрован (например «треки этого исполнителя»), кнопка снова загружает выбранную папку библиотеки.

**Двойной щелчок** играет сфокусированный трек (если модуль плеера загружен).

#### Править теги (режим правки)

**Что:** Справа открывает инспектор, сверху — панель групповых действий.  
**Зачем:** Без режима таблица остаётся узкой для просмотра. С ним можно править теги, переименовывать и откатывать.  
**Как:**

1. **Править теги** — кнопка потом называется **Правка**.
2. Потяните разделитель между списком и инспектором, если нужно больше места для тегов.
3. Нажмите ещё раз, чтобы выйти из режима.

При **входе** в режим правки Buran запоминает состояние каждого трека (теги **и** имя файла). При **выходе** сохранённое состояние становится новой базой.

#### Инспектор — один трек

Инспектор всегда относится к **сфокусированному** треку (выделенная строка), не ко всем галочкам.

| Поле / кнопка | Что делает | Зачем | Как пользоваться |
|---|---|---|---|
| **Название, альбом, год, комментарий** | Сразу пишет значение в файл. | Опечатки, нет года, мусор в комментариях. | Щёлкните поле, измените текст, уйдите с поля — готово. |
| **Исполнители / жанры / настроения** | Списки с × для удаления и + / Enter для добавления. Подсказки из каталога. | Несколько исполнителей (`feat.`), несколько жанров, настроение отдельно от жанра. | Введите имя, выберите из списка или создайте, + или Enter. |
| **Имя →** (ID3 → имя файла) | Собирает `Исполнитель - Название.mp3` из тегов и переименовывает файл. Берутся предпочтительные имена каталога. Два исполнителя → `A feat. B`, больше → `A feat. B, C & D`. | Имя файла и теги должны совпадать. | Сфокусируйте трек, **Имя →**. Строка остаётся выбранной. |
| **← Имя** (имя файла → ID3) | Разбирает имя файла по шаблонам (исполнитель, название, альбом, год, live/remix …) и пишет теги. | Имена чистые, теги пустые или неверные. | Сфокусируйте трек, **← Имя**. |
| **Сброс** | Возвращает теги **и** имя файла к состоянию **на начало этой сессии правки**. | Случайное переименование или испорченные теги, даже после перехода на другой трек и обратно. | Оставайтесь в той же сессии правки, снова сфокусируйте трек, **Сброс**. |

Неизвестные имена, которые не заблокированы, становятся предпочтительной записью каталога. Заблокированные значения попадают в файл, но не в базу.

При **открытии папки** Buran заменяет альтернативные написания в файлах на предпочтительное имя каталога и сохраняет это.

#### Групповые действия (отмеченные файлы)

Только в режиме правки и только для строк с галочкой.

| Кнопка | Что делает | Зачем | Как |
|---|---|---|---|
| **Все / Нет** | Отметить или снять все файлы. | Обработать всю папку сразу. | **Все**, действие, **Нет**, когда закончили. |
| **Исполнители / жанры / настроения** | Открывает групповой диалог. Список — **объединение** всех выбранных файлов. | Удалить «Pop» только там, где он есть; добавить «Freestyle» **каждому** файлу. | Галочки → кнопка → × или добавить → **Применить**. |
| **Комментарии** | Один текст на все выбранные файлы или очистить комментарии. | ID3-комментарии забиты мусором плеера. | Введите текст и **Применить**, или оставьте поле пустым / **Очистить**. |
| **Играть** | Передаёт выбор плееру. | Послушать, не ища вкладку плеера. | Галочки → **Играть**. |
| **В плейлист** | Добавляет выбор в текущий плейлист. | Подборка через границы папок. | Галочки → **В плейлист**. |
| **Имя файла из ID3** | Как **Имя →**, для всех галочек. | Переименовать папку по схеме тегов. | Галочки → кнопка. |
| **ID3 из имени файла** | Как **← Имя**, для всех галочек. | Теги из чистых имён для всей папки. | Галочки → кнопка. |

**Групповой диалог исполнителей / жанров / настроений**

1. Отметьте файлы.
2. **Исполнители**, **Жанры** или **Настроения**.
3. × удаляет запись **только там, где она есть**. У другого файла она остаётся.
4. Добавление имени (или пометка **все**) ставит его на **каждый** выбранный файл — даже если оно уже было в объединённом списке. Можно снять жанр из списка и сознательно снова назначить всем.
5. **Загрузить из выбора** пересобирает список, если вы меняли галочки.
6. **Применить** пишет теги.

#### Имя файла из ID3 — конфликт имён

Если целевой файл уже есть, открывается **Сравнить файлы**: размер, изменение, длительность, битрейт, частота, каналы, разрядность, формат.

| Кнопка | Действие |
|---|---|
| **Оставить оба** | Отменить переименование. Оба файла остаются. |
| **Оставить этот файл** | Удалить существующий и переименовать текущий. |
| **Оставить существующий** | Удалить текущий и оставить существующий. |

#### ID3 из имени файла — как думает разборщик

- Шаблоны и ключевые слова делят имя на исполнителя, название, альбом, год и пометки версии.
- Запятая и точка с запятой всегда разделяют.
- `feat.` / `ft.` / `featuring` — в том числе в скобках, например `Eminem - Stan (feat. Dido).mp3` — это **дополнительные исполнители**, не комментарий.
- `(Live)` или `[Remix]` остаются комментарием.
- Известные имена каталога и однобуквенные группы вроде `D & F` не режутся на `D` и `F`.
- Дополнительные разделители задаются в редакторе БД в **Ключевых словах**.

### Новые значения для базы

**Что:** Диалог после загрузки папки, если в тегах или именах файлов есть имена, которых ещё нет в каталоге и которые не заблокированы.  
**Зачем:** Один раз решить, «Gwen Stefani» — новый исполнитель, альтернативное написание известного или мусор, который больше не показывать.  
**Как:**

1. Откройте папку. Диалог появляется, только если есть неизвестное.
2. У каждой записи галочка: принять или пропустить.
3. **Предпочтительное имя** — новая запись каталога (написание, которое должно попадать в файлы).
4. **Альтернативное имя** — опечатка или другое написание существующей записи. Для исполнителя можно сразу создать и предпочтительное имя.
5. **Блокировать** — больше не предлагать. Жанр `Happy` **не** блокирует настроение `Happy`.
6. Внизу: **Разблокировать** уже заблокированные значения — они снова появятся сверху для импорта.
7. **Применить** пишет только отмеченные записи. **Пропустить** закрывает без изменений каталога.

### Плеер

Отдельный модуль. Играет MP3 и FLAC через **libVLC** (в пакете). Стыкуется под списком редактора (разделитель меняет высоту) и как вкладка **Плеер**.

| Функция | Что делает | Зачем | Как |
|---|---|---|---|
| **Play / Pause / Stop / Назад / Далее** | Транспорт. | Обычное прослушивание. | Панель под списком или на вкладке плеера. |
| **Позиция / громкость** | Перемотка и уровень. | Перейти к месту. | Ползунки. |
| **Спектрограмма** | Частота по времени, считается один раз (похоже на Spek). Оси: Гц, время, дБ до частоты Найквиста файла. | Видно, есть ли у файла «192 кГц» энергия выше 16 кГц; шум и склейки. | Щелчок или протяжка ищут по файлу. Разделитель меняет высоту. |
| **Очередь папки** | Левый список на вкладке плеера: файлы папки библиотеки. | Прослушать папку. | Двойной щелчок играет, **В плейлист** копирует. |
| **Плейлисты** | Правый список: именованные списки через границы папок. | Миксы, «разметить», избранное. | **Новый**, имя, добавить треки. Переименовать в поле имени. **Удалить**. |
| **Импорт / экспорт M3U** | Абсолютные пути. Отсутствующие файлы остаются помеченными. | Обмен с другими плеерами. | Импорт/экспорт на вкладке плеера. |
| **Повтор** | Выкл / все / один / один раз. | Цикл или стоп после этого трека. | Кнопка повтора на панели. |
| **Поменять плеер и вкладки** | Стыковка сверху или снизу. | Больше места списку или спектрограмме. | Кнопка смены. |

Воспроизведение из **плейлиста** продолжается при смене папки. **Очередь папки** останавливается, если текущего трека нет в новой папке.

Без модуля плеера ID3-редактор полностью работает.

### Редактор БД

Вторая вкладка. Здесь **весь каталог**: создать, переименовать, назначить альтернативой, заблокировать, разблокировать. Всё, что умеет диалог импорта, здесь можно вести постоянно.

#### Поиск и обновление

- Поле поиска фильтрует исполнителей, альтернативные имена и ключевые слова.
- **Очистить поиск** сбрасывает фильтр.
- **Обновить** перезагружает каталог.

#### Исполнители

**Что:** Список с предпочтительным именем и необязательным гражданским (`Marshall Mathers` для `Eminem`).  
**Зачем:** Одно каноническое написание, к которому сходятся все варианты.  
**Как:**

- Внизу введите **предпочтительное имя**, при желании гражданское, **Добавить**.
- **Альтернативное имя:** привязать введённое имя к существующему исполнителю. Ввод в поле фильтрует (например `E` → Eminem).
- **Блокировать:** скрыть введённое имя. Если оно уже в каталоге, оно удаляется. Блокировка предпочтительного имени блокирует и его альтернативы.
- Правый щелчок: **Удалить**, **Блокировать**, **Снять выделение**, **Показать треки** (проиндексированные пьесы в ID3-редакторе).

#### Альтернативные имена

Столбец всех альтернатив или только выбранного исполнителя. Для добавления нужен выбранный исполнитель. Удаление и блокировка — правым щелчком или кнопками.

#### Членство

Только при выбранном исполнителе. Участники этой группы или группы, в которые входит исполнитель (`Eminem` в `D12`). Имена уже должны существовать как исполнители. Группа не может быть членом самой себя.

#### Жанры и настроения

Те же приёмы, отдельные списки. Настроения — чувства (`Happy`, `Dark`), не замена жанрам.

- Галочка: назначить жанр или настроение **выбранному исполнителю** (какой репертуар у этого акта).
- Правый щелчок: Удалить, Блокировать, Снять выделение, **Фильтровать по выбору** (список исполнителей), снять фильтр, **Показать треки**.
- Альтернативные написания: варианты выбранной записи (`Danc` → `Dance`).
- Внизу: создать предпочтительное имя, привязать альтернативу, блокировать.

#### Ключевые слова

Разделители и слова распознавания для имён файлов и тегов.

| Тип | Назначение | Примеры |
|---|---|---|
| **Сотрудничество** | Делит исполнителей. | `feat`, `ft`, `vs`, `with`, `and`, `&`, `+`, `/` |
| **Версия** | Ловит пометки, которые остаются комментарием. | `Live`, `Remix`, `Remaster` |

Запятая и точка с запятой всегда разделяют. `&` можно убрать здесь, если имя `D & F` не должно резаться.

#### Заблокированные значения

Нижняя полоса, отдельно для исполнителя, жанра и настроения. **Разблокировать** снова разрешает имя как подсказку. Запись каталога сама не возвращается — её добавляют заново намеренно.

Позднейшее добавление того же написания в каталог снимает блокировку только для этого написания.

### Модель каталога

Три отдельных вида: **исполнитель**, **жанр**, **настроение**.

| Вид | Смысл |
|---|---|
| **Предпочтительное имя** | Написание, которое должно попадать в файлы. |
| **Альтернатива** | Другое написание той же записи. При загрузке папки подменяется автоматически. |
| **Заблокировано** | Не появляется в диалоге импорта и не попадает в каталог молча. |

Блокировка действует только на выбранный вид. Одна и та же строка может быть заблокирована как жанр и разрешена как настроение.

## Где Buran хранит данные

Музыкальные файлы Buran трогает, только когда вы пишете теги или переименовываете. Каталог и настройки отдельно:

| Система | Место |
|---|---|
| Linux | `~/.local/share/Buran` |
| Windows | `%LOCALAPPDATA%\Buran` |

Файл SQLite исторически называется `CerberusMusicManager.db`. Удаление приложения эту папку не трогает, чтобы каталог сохранился.

## Релизы на GitHub

Каждый релиз с новым номером версии в `Directory.Build.props` после push в `master` собирает:

- Linux `.rpm` (и `.deb`)
- Windows `setup.exe` и портативный `.zip`

Обычный push кода без повышения версии только компилирует (зелёная галочка **Build**). Установщики появляются, когда версия новая, меняется `packaging/` или workflow пакета, либо вручную: **Actions → Package → Run workflow**.

## Сборка самостоятельно

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download) (см. `global.json`).

```bash
dotnet build BuranMusicLibraryManager.sln -c Release
```

В JetBrains Rider откройте solution и запускайте / собирайте как обычно.

Пакеты Linux на машине Fedora/Bazzite (библиотеки VLC упаковываются):

```bash
bash packaging/pack.sh linux
```

Результат в `dist/` (в gitignore), например `buran-<версия>-4.x86_64.rpm`.

Windows-установщик собирается в GitHub Actions (Inno Setup). Локально на Windows, если `iscc` в PATH:

```bash
bash packaging/pack.sh windows
```

---

Buran сразу пишет теги, помнит ваш каталог и играет через встроенный libVLC. Если что-то ещё неясно: в приложении **Настройки → Руководство**.
